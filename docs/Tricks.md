# 已实施训练 Tricks（截至当前）

## 1) 轻量奖励塑形（environment）
- 接近终点给正奖励，远离终点给对称负奖励。
- 非沙暴且未挖矿时，原地不动追加小惩罚（抑制无效停留）。
- 首次挖矿给额外一次性奖励（鼓励探索矿点）。
- 终点奖励加强，显著拉开“到达终点”与“早死/超时失败”的回报差。

目的：减少“短局早死也不亏”的局部最优，让策略更倾向于完成任务。

---

## 2) day0 最低采购策略（agent）
- 在第0天可购买时，强制采购下限：`buy_water >= floor_water`、`buy_food >= floor_food`。
- 下限由 `_day0_purchase_floor` 统一控制，当前为不超过上限的 `90/90`。
- 该下限同时作用于：
	- 正常采样分支（stochastic）
	- 确定性分支（deterministic）
	- epsilon 随机探索分支（epsilon-greedy）

目的：避免“开局买太少→2步耗尽资源→反复早死”的训练塌陷。

---

## 3) epsilon 探索分支允许挖矿（agent）
你问的“`epsilon` 探索分支不再固定 `mine=False`”意思是：

- 以前：只要进入 epsilon 随机动作，就**永远不挖矿**，`mine` 被硬编码为 `False`。
- 现在：如果当前状态 `can_mine=True`，epsilon 分支会按概率随机设置 `mine`（当前约 `30%`）。

影响：探索期会真实覆盖“挖矿动作”，否则策略网络几乎拿不到挖矿相关样本，`mine_count` 长期接近 0。

---

## 4) PPO 稳定化（config + ppo）
- 更保守超参：
	- `LR_ACTOR = 5e-5`
	- `LR_CRITIC = 2e-4`
	- `EPOCHS_PER_UPDATE = 4`
	- `ENTROPY_COEF = 0.03`
	- `TARGET_KL = 0.01`
- PPO 更新中加入 KL 早停：超过 `TARGET_KL` 立即停止本轮剩余 epoch。
- 保留价值裁剪与梯度裁剪，减少策略突变和价值发散。

目的：在保留探索的同时抑制训练震荡。

---

## 5) 探索率调度与日志诊断（train + ppo）
- epsilon 线性衰减：`0.30 -> 0.05`（前 70% 训练回合）。
- 训练日志增加滚动窗口行为统计：移动/停留/挖矿/购买/购水/购食。
- 更新诊断增加：
	- `effective_updates`
	- `target_kl_hit`
	- `ratio[min,max]`
	- `explained_variance`

目的：不只看成功率，还能快速判断“是否在学”“学歪在哪”。

---

## 建议用这 3 个指标判断 tricks 是否生效
1. `最近100局行为: 均挖矿` 是否从接近 0 提升。
2. `最近100局成功率` 是否稳定高于旧基线。
3. `本回合步数/均天数` 是否摆脱大量 2 步早死。

若这三项同时改善，说明当前 tricks 组合在起作用。
