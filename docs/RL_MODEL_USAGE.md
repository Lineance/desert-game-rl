# 当前 RL 模型使用说明

本文档用于说明：`task2` 当前强化学习实现中，哪些行为属于“题目目标”，哪些属于“模型设计（训练策略）”。

---

## 1. 模型定位

当前实现是 **PPO + Belief 特征 + 动作掩码** 的部分可观测决策方案：

- 观测输入：环境状态特征 + 当天天气 + 地点类型 + 信念特征
- 策略网络：`src/models/agent.py` 的多头 Actor（move / mine / buy_water / buy_food）
- 价值网络：同文件 Critic
- 训练器：`src/models/ppo.py`
- 环境规则与奖励：`src/env/environment.py`

这意味着：**策略学习依赖环境返回的奖励信号 + 训练阶段的探索/稳定化机制**，两者共同构成当前模型设计。

---

## 2. “任务目标”与“训练设计”的关系

### 2.1 任务目标（最终优化方向）

从任务本质看，核心目标是：

- 合法生存并到达终点
- 最大化最终资金（含终点退款逻辑）

### 2.2 训练设计（为可学习性服务）

在实际 RL 训练中，仅使用稀疏终局信号通常学习效率很低，因此当前实现引入了**奖励塑形与探索策略**：

- 奖励塑形：在不违反规则前提下，给过程行为提供额外学习信号
- 探索策略：在采样阶段提升关键动作（如挖矿）的覆盖率

结论：

- 这类“硬编码奖励/探索规则”不是题目规则本身；
- 但在工程实现上，确实是**当前 RL 模型设计的一部分**。

---

## 3. 当前实现中的关键设计点（与代码一致）

### 3.1 环境侧奖励信号（`src/env/environment.py`）

环境返回的 `reward` 包含：

- 终局结果相关奖励（成功到达 / 失败惩罚）
- 过程塑形项（如挖矿激励、路径倾向、无效停留抑制等）

因此当前 reward 不是“纯最终资金差”单一信号，而是**目标信号 + 训练塑形信号**的组合。

### 3.2 训练侧探索与稳定化（`src/models/ppo.py`）

训练阶段包含：

- GAE、PPO clip、value clip、entropy bonus、梯度裁剪
- `TARGET_KL` 早停（抑制策略突变）
- 采样阶段对关键行为覆盖的策略化处理（用于避免关键动作样本过少）

这些也属于模型设计，而非题目业务规则。

---

## 4. 为什么这样做是合理的

在部分可观测、稀疏奖励任务中：

- 仅靠终局奖励，策略常陷入“短视/保守”局部最优
- 合理塑形可显著提高样本效率与可训练性
- 但塑形必须服从规则约束，不能改变动作合法性与状态转移

本项目通过：

- 环境规则严格约束（合法动作、消耗、负重、资金、终止条件）
- 测试层面对规则一致性持续校验（见 `tests/` 与 `docs/RULES_AUDIT.md`）

来保证“训练技巧”不越过题目规则边界。

---

## 5. 使用建议（当前版本）

- 若目标是**复现实验表现**：保持当前 reward 与训练策略配置。
- 若目标是**研究纯任务回报**：建议后续拆分为
  - `base_reward`（任务目标）
  - `shaping_reward`（可开关/可配权重）

当前仓库仍以“可训练、可收敛、规则一致”为优先，故保留上述设计。
